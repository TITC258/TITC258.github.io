GitHub 仓库

访问令牌（细粒度 token）只授权本仓库 · 仅“内容读写” · 建议设有效期

令牌由你在 GitHub 官方页面亲手创建（GitHub → Settings → Developer settings → Fine-grained tokens）， 选择仅这一个仓库，权限勾选 Contents 读写。可随时在 GitHub 一键作废。
